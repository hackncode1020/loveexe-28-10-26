# LOVE.exe 💾❤️

A retro Windows-style installer that installs **LOVE**. Type their name, press **Install**, watch it scan your heart (found 1 crush ❤️), remove ego.dll, get stuck installing hugs at 99%… and finish with a glowing pixel heart, fireworks of tiny hearts and **I LOVE YOU, <name>**.

🔗 **Live:** https://loveexe-hackncode.sites.tab.bot/

💌 Personalise it: `https://loveexe-hackncode.sites.tab.bot/?name=YourPerson`

## Features
- Win98 setup wizard look, CRT scanlines, pixel font
- Funny install steps + progress bar with a 99% "hugs" stall
- Pixel heart drawn on canvas with a heartbeat glow + heart fireworks
- `?name=` personalisation (default: *For you*), Share button (Web Share API / copy link)
- Plain HTML, CSS & JavaScript, no libraries, mobile-first

## Run locally
Open `index.html` in a browser. That's it.

## Files
- `index.html` — layout
- `style.css` — retro Windows styling
- `script.js` — installer timeline, pixel heart, fireworks, share
